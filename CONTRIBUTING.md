# Contributing

Bug reports and pull requests are welcome.

- Set up: `python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt`
- Run the tests before you push: `.venv/bin/python -m pytest -q` (no network needed)
- Keep code, comments and commit messages in English; one topic per pull request.
- YouTube changes often. If you fix a breakage, say in the pull request what stopped working and how you checked the fix.
